---M3D NOTES---


model3d can be tricky. heres some stuff to remember.


CURRENT CONFIG:
---
scale 2.0
include normals
include uvs
write armature
write animation
use gridcompression
use streamcompression

---

options:


- Scale
    scale of it. 2.0 used currently. can be negated by gridcompression

- selection only
    only export selection. can do model and rig, but whole thing is usually easier
    
- apply modifiers
    apply any modifiers used. usually not necessary.
    
- Include Normals
    write normals of model. pretty important.
    
- Include UVS
    write UV coords (texture). important
    
- Include Vertex Colors
    vertex colors. not really used
    
- Write Shapes
    write as shapes. not really used
    
- Write Materials
    write materials used. not important if not using materials
    
- Write Armature
    write armature rig. important for anims
    
- Write Animation
    write animation data. important
    
- Use Markers
    markers instead of animation actions. probably not useful
    
- FPS
    fps
    
- Precision
    compression stuff. 8 bit can be too low and cause texture bleeding. 16 bit is fine. auto may do 8 bit
    
- Embed Assets
    compile all assets (texture and such) in file. not ideal since it both requires double loading for grabbing textures and such, and is less modification friendly
    
- Use GridCompression
    compression for smaller models. good, but can severely extend export time
    
- Use Streamcompression
    some default. needed.
    
- Use ASCII variant
    not sure. not used
